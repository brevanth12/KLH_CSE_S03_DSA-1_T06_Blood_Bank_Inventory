## Abstract

LifeLink: Blood Bank Inventory is a Java-based application developed to manage blood bank information efficiently by maintaining donor details, organizing blood group records, and monitoring the availability of blood units. The application allows users to add and manage donor information, view available blood groups, update inventory records, and search for required blood group details. It also includes a basic blood group compatibility checking feature using predefined programming logic. The project demonstrates the practical application of Data Structures and Algorithms concepts in Java, including arrays, two-dimensional Boolean arrays, searching, and updating operations. Overall, LifeLink aims to reduce manual record-keeping efforts and provide a simple, systematic, and efficient approach to blood bank inventory management.
